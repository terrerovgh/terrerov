# Terrerov

Single-page interactive site: a Temple of Heaven curtain that forms a scannable QR to [terrerov.com](https://www.terrerov.com).

Based on [CodeMaryy/temple-of-heaven-curtain](https://github.com/CodeMaryy/temple-of-heaven-curtain) — physics, paper/ink editorial, and the original roof studies (cutout, enhanced, crop, watercolor).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Cloudflare Pages / Workers via `@astrojs/cloudflare` — build output `dist/client`.

## Credits

Temple assets and curtain interaction model adapted from the Temple of Heaven Curtain project.
